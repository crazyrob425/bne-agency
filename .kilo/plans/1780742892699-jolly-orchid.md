# Plan — Fix Site Load Errors & Ensure Clean Startup

## Problem Statement
The user wants to open the site with `pnpm dev` and make sure no errors appear on load.

## Investigation Plan (Read-Only First)

1. **Check `main.tsx` imports** — `@/lib/trpc` and `@shared/const` may be missing/unused
2. **Check public assets** — `favicon.png` referenced in `index.html` may not exist in `client/public/`
3. **Check CSS entry** — `./index.css` may have missing font references or Tailwind config issues
4. **Check router setup** — `wouter` `Switch` usage with React 19 compatibility
5. **Check for console errors** — run `pnpm dev` and observe terminal + browser console

## Execution Plan (After Plan Exit)

### Step 1: Static Asset Verification
- Verify `client/public/favicon.png` exists; add placeholder if missing
- Move `robots.txt` and `sitemap.xml` from `client/src/pages/` to `client/public/` so they are served as static files

### Step 2: Fix main.tsx Unused Imports
- Remove unused `UNAUTHED_ERR_MSG` import from `main.tsx`
- Verify `@/lib/trpc` actually exists and exports `trpc`

### Step 3: CSS / Font Verification
- Inspect `client/src/index.css` for Tailwind directives and font-face references
- Ensure Google Fonts in `index.html` match what Tailwind classes expect

### Step 4: Run Dev Server & Observe
- Run `pnpm dev` 
- Check terminal output for build/runtime errors
- Open browser console and check for 404s, Failed to load resource, or JS errors

### Step 5: Fix Identified Issues
- Address any import/module errors
- Fix any missing static assets
- Ensure splash page renders without React errors

## Risk Assessment
- Low risk: mostly verification and minor cleanup
- No database or backend changes involved

## 3. Migration Approaches — Comparison

### Option A: Manual Reconstruction on Wix Editor (RECOMMENDED)

**Process**: Rebuild page-by-page in Wix Editor (Velo/Wix Studio if needed)

| Dimension | Assessment |
|-----------|-----------|
| Design fidelity | HIGH — pixel-perfect match possible with Repeat Elements + custom CSS |
| SEO preservation | HIGH — Wix SEO panel handles meta, canonical, OG, sitemap |
| Form migration | MEDIUM — Wix Forms for static forms; Velo code needed for Apply wizard |
| Tool reimplementation | LOW — interactive tools (calculator, niche matcher) need Velo JS or embedded iframe |
| Animation fidelity | LOW-MEDIUM — Framer Motion animations must be rebuilt with Velo APIs or CSS |
| Backend reimplementation | N/A — must use Wix Velo HTTP functions or external backend |
| Time estimate | 8-12 weeks (1 designer + 1 dev) |
| Ongoing cost | Wix Business/Enterprise plan (~$50-150/mo) |
| Risk | Wix platform limitations (max 100 pages, custom code sandboxing) |

**Platform limitations to note**:
- Wix SSO/Auth: Wix Members + custom Velo/OAuth app
- Stripe: Wix native Payment Integration (covers subscriptions)
- File uploads: Wix Input File Upload + Wix Media Manager
- Media: Must be re-uploaded (Wix has 50GB+ storage on Business)
- Custom fonts: Wix allows font uploads (50 font families max on most plans)

---

### Option B: Automated Migration (Site Migration Tool / Webflow import / Wix ADI)

**Process**: Use Wix ADI or import from sitemap

| Dimension | Assessment |
|-----------|-----------|
| Design fidelity | LOW — design system is too custom, ADI will oversimplify |
| SEO preservation | MEDIUM — URLs can be 1:1 but structured data needs manual fixing |
| Functional elements | VERY LOW — front-end logic, animations, and backend will break |
| Time estimate | 1-2 weeks but with massive rework |
| Risk | HIGH — most automated tools can't handle React SPA + custom backend |

**Verdict**: NOT suitable. This site has heavy custom JS, interactive tools, and a bespoke dark design system that no automated importer can handle.

---

### Option C: Embed Approach (Iframe Wrapper)

**Process**: Host current site as-is on Vercel/Netlify, embed in a Wix iframe

| Dimension | Assessment |
|-----------|-----------|
| Design fidelity | 100% |
| SEO preservation | NONE — Wix sees only iframe, search engines index nothing |
| Functionality | 100% |
| Time estimate | 1-2 days |
| Risk | Wix iframes are disallowed on free/basic plans |

**Verdict**: Only viable if SEO is non-critical and Wix iframe embedding is available on your plan.

## 4. Recommended Approach: Optimal Phased Migration

### Phase 1: Inventory & Asset Extraction (Week 1)
1. Export all media: `client/public/`, `BNE logo*.png`, `BNE businesscard.png`
2. Document every custom font in `media/fonts/`
3. Export blog articles from `client/src/data/blogArticles.ts` (12 articles, ~30k words)
4. Document all Stripe product IDs and pricing
5. Export any Google Sheets / database content
6. 301 redirect map from old URLs → new Wix URLs (preserve path structure: `/tiers` → `/service-tiers` etc.)
7. Export current Google Analytics, Search Console data

### Phase 2: Wix Site Setup (Week 1-2)
1. Create Wix account → create new site
2. Upload all brand fonts via Wix Font Manager
3. Upload logos and brand assets
4. Set up Wix Payments / Stripe integration
5. Configure Wix SEO defaults (site title, meta description, OG settings)
6. Set up custom domain transfer: `blackisted.studio` → Wix

### Phase 3: Core Layout Reconstruction (Weeks 2-4)
1. **Header/Navigation**: Rebuild fixed nav with glassmorphism in Wix Editor, set up Wix Router pages
2. **Footer**: Rebuild as Wix Footer (strip + drop zones)
3. **Home page**: Section-by-section rebuild using stacked Sections and Strip Containers
4. **Apply Wizard**: Use Velo code for the multi-step flow; Wix Forms for basic fields, Velo `$w` API for conditionals and file upload
5. **Service Tiers + Tools listing**: Grid layouts with hover effects

### Phase 4: Content Pages (Weeks 4-6)
1. **Blog**: Use Wix Blog app or Wix Stores (for article layout); import all 12 articles manually or via CSV
2. **Article Detail**: Wix dynamic pages (blog automatically generates these)
3. **Legal Vault**: Framer-style collapsible sections
4. **Media Downloads**: Wix File Upload (member-only) or Velo download handler
5. **Pricing**: Wix Pricing Plans app (or custom with Velo + Stripe)
6. **Remaining pages**: Services, InPerson, Onboarding, PaymentSuccess, MarketingAssets, CreatorTools hub

### Phase 5: Backend Migration (Week 6-7)
1. **Stripe**: Transition to Wix Native Payment Integration; map old product IDs
2. **User Auth**: Transition to Wix Members/Lightboxes
3. **File uploads**: Wix Media Manager API
4. **Map**: Wix Map app or embed Google Maps
5. **Analytics**: Wix Analytics (or keep Google Analytics via Velo)

### Phase 6: SEO & Testing (Week 7-8)
1. Match all old URL slugs → Wix dynamic page slugs
2. Configure 301 redirects (Wix URL Redirect Manager)
3. Verify meta tags, OG images, Twitter cards on every page
4. Submit new sitemap to Google Search Console
5. Run Wix Site Check
